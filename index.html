How Algorithms Work

BFSExplores level by level from the start node using a queue. Finds the shortest path in an unweighted maze.
DFSExplores as deep as possible along one path using a stack, and backtracks when it reaches a dead end.
A* SearchUses f(n) = g(n) + h(n), where g(n) is the cost travelled and h(n) is the estimated cost to the goal.
f(n) = g(n) + h(n)
Greedy Best-FirstSelects the node that looks closest to the goal, based mainly on the heuristic h(n).

How the System Works

  1. Create or generate a maze.
  2. Set start and goal positions.
  3. Add obstacles or walls.
  4. Select an AI search algorithm.
  5. Visualize the search process and reconstruct the path.
  6. Display performance results and compare all algorithms.
